### 🟢 问题 3：`InventoryBatchService.create()` 参数为裸 Entity 而非 DTO

**文件：** `InventoryBatchService.java` 行 37

```java
public Long create(InventoryBatch batch) {  // ← 直接暴露 Entity
    if (batch.getRemainingQuantity() == null) {
        batch.setRemainingQuantity(batch.getQuantity());
    }
    inventoryBatchMapper.insert(batch);
    return batch.getId();
}
```

**问题：** 项目中其他所有 Service 的 create 方法都接收 DTO（如 `ExpenseCreateRequest`、`PurchaseRequestCreateDTO`），唯独这里是裸 Entity。前端传什么字段就能 set 什么字段，存在 over-posting 风险。

**建议：** 改为接收 DTO（`InventoryBatchCreateRequest`），参照其他 Service 风格。
